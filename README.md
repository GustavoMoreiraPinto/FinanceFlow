
# 💸 FinanceFlow

Dashboard de controle financeiro pessoal desenvolvido com React e TypeScript, com foco em organização de receitas, despesas, acompanhamento de resultados e visualização de dados financeiros.

## 📊 Sobre o projeto

O FinanceFlow é uma aplicação web que permite registrar movimentações financeiras e acompanhar o desempenho mensal e anual por meio de indicadores e gráficos interativos.

O projeto foi desenvolvido para colocar em prática conceitos de desenvolvimento front-end, gerenciamento de estado, persistência de dados e visualização de informações.

## ✨ Funcionalidades

- Cadastro de receitas e despesas
- Edição e exclusão de transações
- Organização de despesas por categorias
- Filtro de transações por mês
- Dashboard com visão geral anual
- Indicadores de receitas, despesas e resultado líquido
- Gráfico de receitas e despesas por mês
- Gráfico de evolução do resultado acumulado
- Gráfico de despesas por categoria
- Cálculo da taxa de poupança
- Definição e acompanhamento de metas anuais
- Indicadores de desempenho financeiro
- Ranking das maiores categorias de despesas
- Armazenamento local das informações

## 🚀 Como executar o projeto

### Pré-requisitos

- Node.js
- npm
- Git

### Instalação

Clone o repositório:

```bash
git clone https://github.com/GustavoMoreiraPinto/FinanceFlow.git
```

Entre na pasta:

```bash
cd FinanceFlow
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Abra no navegador o endereço informado pelo Vite.

### Build de produção

```bash
npm run build
```

## 💾 Armazenamento de dados

O FinanceFlow utiliza o LocalStorage do navegador para armazenar transações e metas financeiras.

As informações permanecem disponíveis no mesmo navegador, mas não são sincronizadas entre dispositivos.

Limpar os dados do navegador pode remover as informações armazenadas.

## 📈 Indicadores financeiros

O dashboard apresenta:

- Receitas e despesas anuais
- Resultado líquido acumulado
- Taxa de poupança
- Meses com resultados positivos e negativos
- Melhor mês registrado
- Médias de receitas e despesas
- Progresso da meta anual
